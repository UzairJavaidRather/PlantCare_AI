# bob/ — IBM Bob Contribution Folder

## Purpose

This folder documents IBM Bob's role in the PlantCare AI project. It contains professional documentation produced with Bob's assistance, covering product ideation, architecture analysis, AI-for-sustainability analysis, and future IBM integration planning.

This folder does **not** contain application source code and was not generated by the PlantCare application itself.

---

## Why IBM Bob Was Used

PlantCare was developed as an internship/learning project focused on full-stack development, applied AI/ML, and sustainability-focused product thinking. IBM Bob was employed as a development assistant to:

- Rapidly understand and document an existing codebase
- Provide structured ideation frameworks
- Analyse system architecture from source code
- Generate professional technical documentation
- Identify AI/sustainability strengths and weaknesses
- Plan potential future IBM technology integrations

Bob was **not** used to write the PlantCare application code itself. Its contribution is analytical and documentary in nature.
